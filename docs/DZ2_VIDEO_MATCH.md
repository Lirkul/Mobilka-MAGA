# ДЗ2: доработка по записи ДЗ1

Референс: [описание исходного видео](../reference/video/README.md), 50,736 секунды.
Само видео хранится локально и не публикуется в Git.
Главная, Expo Router, асинхронный mock API и очередь сохранения прогресса
сохранены. Сервер, OpenAPI и зависимости не добавлялись.

## Расхождения и исправления

| Компоненты | До | После |
| --- | --- | --- |
| `FilterPicker`, `genreTree` | Неполный список, заголовки без поведения родительской категории | Полное прокручиваемое дерево из видео без исключённого пользователем жанра. Выбор категории отмечает и блокирует её дочерние строки; в фильтр передаётся одна категория. Отмена сохраняет прежние условия. |
| `filterBooks` | Нельзя было найти книги по общей категории, если в данных указан поджанр | При сопоставлении поджанр учитывает родительскую категорию. Между всеми выбранными условиями остаётся AND. Исключение категории исключает её поджанры. |
| `SearchPanel`, `DrawerShell`, `MotionSurface`, `Expandable` | Только затемнение, раскрытие без движения | Выезд меню с соответствующего края, появление панели снизу, увеличение диалогов и плавное раскрытие дополнительных параметров. |
| `LibraryStatusModal` | Центрированный диалог с радиокнопками | Нижнее окно «Пометить как» с четырьмя статусами и значками, как в записи. Изменение статуса использует прежнее хранилище. |
| `BookScreen` | Упрощённые действия и статистика | Три показателя, покупка/чтение у платных книг, ссылка на цикл, ряд статуса и дополнительных действий, раскрываемая аннотация, строки статистики и рецензий. |
| `ReaderScreen` | Шапка с названием, неподвижный индикатор прогресса | Панель со значками из видео, оглавление и перемещение по главе ползунком, расчёт страниц по высоте текста, ночной режим. Нажатие на текст скрывает/возвращает панели. |
| `ReaderLoading` | Общий небольшой индикатор «Загрузка» | Светлый экран «Готовимся к чтению» со значком книги, как на 00:34 записи. При смене главы используется её текущая тема. |
| `ReaderSettingsModal`, `readerOptions`, `Slider` | Два фона и размер шрифта | Светлая панель без затемнения текста: пять фонов, выбор шрифта, размер, выравнивание, прокрутка/постраничный режим, яркость и жест у левого края. Дополнительно регулируются интервал, поля и расстояние между абзацами. |
| `appState` | Сохранены только старые поля читалки | Новые поля дополняют сохранённые настройки. Прежние тема, размер, библиотека и прогресс не сбрасываются. |

«Фантастика» — одно условие категории, которому соответствует любой её поджанр.
Выбор двух отдельных поджанров требует наличия обоих. Контрольный пример
«Темное фэнтези» + «Боевая фантастика» + «В процессе» + «Свободный» по-прежнему
возвращает только `book_001` и `book_019`. Поиск по тексту не использует эти фильтры.

## Как проверить вручную

На работающем Expo Web откройте `http://localhost:8085` в мобильном размере
393 × 852. Если сервер остановлен: `npx expo start --web --port 8085`.

1. Лупа → «Жанр» → «Фантастика». Дочерние строки отмечены и недоступны
   по отдельности. «ВЫБРАТЬ» → «ПОДОБРАТЬ» → выдача с этим условием.
2. Повторите контрольный подбор из четырёх условий выше. Сбросьте фильтры,
   найдите `Город под чёрным солнцем` через поле ввода: оба сценария независимы.
3. Откройте книгу, раскройте аннотацию, измените статус через «Пометить как».
   «Не интересно» исключает книгу из последующей выдачи.
4. «ЧИТАТЬ» → следующая глава → переместите нижний ползунок. Проверьте,
   что перемещается сам текст. Оглавление позволяет выбрать конкретную главу.
5. Шестерёнка → измените фон, шрифт, выравнивание, размер и режим чтения.
   «Постранично» перелистывает отдельные страницы влево/вправо; «Прокрутка»
   возвращает свободное вертикальное движение с остановкой в любом месте.
   Перетаскивание яркости меняет видимый текст.
6. Включите регулировку яркости жестами, закройте панель и проведите вверх/вниз
   у левого края. Нажмите на текст: панели скроются; нажмите ещё раз — вернутся.
7. Обновите страницу. Глава, фактическая позиция текста и настройки сохраняются.
   Проверьте возвращение назад, закрытие по свободной области и Escape в Web
   / системной кнопкой «Назад» на Android.

## Проверки и границы

`scripts/check-video-scenario.cjs` проверяет шаги записи, реальное перемещение
панелей по промежуточным кадрам, подбор, нижнее окно статуса, раскрытие аннотации,
перемещение текста ползунком, переключение горизонтальных страниц, пять фонов, яркость,
жест, шрифт, выравнивание, полноэкранное чтение и восстановление после F5.
Контекст браузера изолирован от пользовательского сохранения.

`tests/videoScenario.test.mjs` проверяет дерево, AND для отдельных жанров,
исключение родительской категории и дополнение старых настроек без потери данных.
Остальные проверки приложения остаются в `scripts/` и `tests/`.
Команды и общие результаты — в [визуальном обзоре](DZ2_VISUAL_REVIEW.md).
Скриншоты прогона сохраняются в `.expo/verification/video-scenario/` и не входят в Git.

Яркость регулирует отображение страницы приложения, а не системную яркость
устройства; Auto возвращает обычное отображение. Шрифт Roboto включён в сборку,
остальные варианты используют системные семейства соответствующей платформы.
Пагинация горизонтальная: размер страницы зависит от экрана и настроек текста.
Текст измеряется настоящими компонентами React Native; разрыв возможен внутри
абзаца на границе слов. Один свайп / перетаскивание мышью переворачивает одну
страницу, отдельные кнопки работают так же. `check-reader-modes.cjs` проверяет
оба режима, mouse/touch, полный текст, размещение и F5 на двух размерах экрана;
сохранение остаётся привязано к главе и позиции внутри неё. Отображаемый процент
рассчитывается по всей книге с учётом длины глав; 100% — конец последней главы.
Старые сохранения продолжают восстанавливать прежнее место чтения. Число страниц отличается
от оригинального контента. Покупка и аудиозапись не подключены; кнопки показывают
доступность бесплатного фрагмента / отсутствие аудио в локальном наборе.
Профиль и комментарии используют существующие учебные данные. ДЗ3 не выполнялось.

Android export проверяет сборку JavaScript и ресурсов, но не заменяет запуск
APK на устройстве. Физическое устройство в этой сессии недоступно.
