# Визуальная доработка ДЗ2

Сравнение выполнено по оригиналам `reference/screenshots/`, схеме переходов
`reference/diagram/`, наборам `AuthorToday_refs_v2/original/` и
`AuthorToday_refs_v3/original/`, затем по [видео ДЗ1](../reference/video/README.md).
Изображения `current-implementation` использованы
только как история реализации. Скриншоты не заменяют компоненты интерфейса.

## Границы итерации

- Главная страница, маршруты и слои данных сохранены.
- Асинхронный mock API, идентификаторы книг/глав и очередь сохранения прогресса
  сохранены. К ответам прогресса добавлен вычисляемый `bookPercent`, к оглавлению —
  длины текстов глав. Использованы существующие методы API. Настройки читалки дополняются
  новыми значениями, сохраняя старую тему, размер, библиотеку и прогресс.
- `filterBooks` научился сопоставлять родительские категории с поджанрами;
  прежние условия AND, исключения и контрольная пара книг сохранены.
- Выбор фильтров остаётся AND, текстовый поиск независим от подбора.
- Сервер, OpenAPI и функции ДЗ3 не добавлены. Новых зависимостей нет.
- Учебные обложки и тексты остаются локальными. Полного совпадения контента с
  Author.Today нет. Покупка и аудио показывают доступность в локальном каталоге;
  платежей и аудиофайлов нет. Яркость меняет отображение страницы приложения,
  не системные настройки устройства. Пагинация вертикальная, число страниц
  рассчитано по фактическому тексту и размеру области чтения.
- Навигационные и пользовательские меню остаются доступны. Светлая шапка
  читалки использует тёмные системные значки; при уходе возвращается светлый
  стиль системных значков остальных тёмных экранов.

## Проверка через Expo Web

Сервер один: `http://localhost:8085`.

```powershell
npx.cmd expo start --web --port 8085
$env:EXPO_WEB_URL='http://localhost:8085'
node scripts/check-dz2-ui.cjs
node scripts/check-video-scenario.cjs
node scripts/check-book-progress.cjs
node scripts/check-reader-modes.cjs
node scripts/check-reader-modes.cjs --small
node scripts/check-web.cjs
node scripts/check-reader.cjs
node scripts/check-reader-focus.cjs
node scripts/check-v2.cjs
node scripts/check-menus.cjs
node scripts/check-library.cjs
npx.cmd expo lint
npx.cmd tsc --noEmit
node --test reference/tests/filterBooks.test.mjs tests/*.test.mjs
```

`check-dz2-ui` проверяет все окна дополнительных параметров, черновик/отмену,
закрытие по затемнению и Escape, контрольную пару book_001/book_019, обе кнопки
карточки результата, вкладки произведения, оглавление и настройки читалки,
обратные переходы, поиск по названию через Enter и кнопку, ширины 320/393/1440.
Существующие проверки отдельно контролируют постоянное состояние и фактическую
прокрутку, offline и повтор запроса. Браузерные контексты тестов изолированы от
пользовательского хранилища.

Снимки до изменений: `.expo/verification/dz2-before/`.
Снимки после изменений: `.expo/verification/dz2-after/`.
Эти локальные изображения игнорируются Git.

Совместимость ресурсов и JavaScript для Android дополнительно проверяется
`npx.cmd expo export --platform android --output-dir .expo/verification/android-export`.
Это проверка bundle; запуск на устройстве и сборка APK ею не заменяются.

Подробности доработки по записи, ручной сценарий и границы реализации:
[DZ2_VIDEO_MATCH.md](DZ2_VIDEO_MATCH.md).
