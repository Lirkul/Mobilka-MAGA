# Author.Today — эталонные скриншоты для разработки

Источник: скриншоты, которые были присланы пользователем в этой переписке.
Всего: 35 JPEG, сохранены без изменения размеров и содержимого. Оригинальные имена оставлены.

Порядок групп по файлам:
- 1000017162.jpg — главная страница
- 1000017163.jpg — панель поиска и подбора поверх главной
- 1000017164–1000017179.jpg — окна фильтров, расширенный подбор, варианты значений
- 1000017180–1000017181.jpg — результаты подбора
- 1000017182–1000017188.jpg — карточка произведения, оглавление, статистика, рецензии, комментарии
- 1000017189–1000017193.jpg — книга, читалка и её настройки/оглавление
- 1000017194.jpg — поиск по названию с клавиатурой
- 1000017195.jpg — результаты текстового поиска по авторам
- 1000017196.jpg — профиль автора

В папке diagram — предоставленная пользователем схема переходов экранов.
В папке overview — контактный лист для быстрой навигации по скриншотам.

Для React Native/Expo: папку screenshots/ можно разместить в reference/screenshots/ проекта.
