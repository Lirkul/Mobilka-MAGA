# Author.Today — дополнительные референсы для Codex (итерация 2)

Это **дополнение** к уже существующим `reference/screenshots/`, `reference/diagram/` и `reference/AuthorToday_mock_kit/`. Не заменяйте старые референсы.

## Куда положить

Распакуйте архив **в корень `reference/`** вашего React Native проекта, сохранив корневую папку архива:

```
author-today-clone/
  reference/
    screenshots/                # предыдущие 35 оригинальных скриншотов
    diagram/                    # ваша схема переходов
    AuthorToday_mock_kit/       # набор мок-данных
    AuthorToday_refs_v2/        # ЭТОТ архив
      original/                 # 11 новых скриншотов ОРИГИНАЛА
      current-implementation/   # 4 изображения ТЕКУЩЕЙ РЕАЛИЗАЦИИ
      docs/                     # промпт, требования, тест-план и превью
```

**Важно:** скриншоты в `current-implementation/` — текущее состояние проекта, а не эталон. Ориентируйтесь для внешнего вида на `original/` и ранее присланные оригиналы в `reference/screenshots/`.

## Главные задачи следующей итерации

1. Внедрить «Моя библиотека» с полками «Читаю», «Прочту позже», «Прочитано», «Не интересно».
2. Сохранять статус книги **и позицию чтения** после переходов, перезагрузки Expo Web и перезапуска приложения.
3. Добавить доступное из меню «Настройки» с **переключателем имитации отсутствия сети**. Это учебное состояние mock API, а не физическое отключение интернета на устройстве.
4. Реализовать полноценные `loading / success / empty / offline / error + retry` для выдачи с учётом новых оригинальных скриншотов.
5. Сделать текстовый поиск отдельно от подбора. В подборе: AND между условиями, включая ВСЕ выбранные жанры.
6. Довести существующие экраны и кнопки до работоспособности, не ломая удачную главную страницу.
7. Профиль автора, произведения, блог и иллюстрации — референсы для второго сценария; подключать постепенно.

## Файлы

- `docs/CODEX_PROMPT.txt` — готовый подробный запрос для Codex.
- `docs/SCREEN_MAP.md` — таблица, какие картинки показывают какие состояния.
- `docs/FEATURE_SPEC.md` — функциональные требования и нюансы логики.
- `docs/ACCEPTANCE_CHECKLIST.md` — что вручную проверить после работы Codex.
- `docs/reference_contact_sheet.jpg` — обзор новых скриншотов.
- `docs/MANIFEST.json` — перечень всех вложений и контрольные суммы.

Примечание: **оригинального скриншота меню настроек с искусственным переключателем сети нет**, потому что это наша учебная функция; сделать её в визуальном стиле оригинала, а не выдавать за дословную копию.
