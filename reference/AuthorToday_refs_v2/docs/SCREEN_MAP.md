## Другие старые референсы

Продолжайте использовать `reference/screenshots/` для карточки книги, читалки, настроек читалки, модального окна фильтров и других ранее снятых состояний. Для поиска и фильтров актуальна также `reference/diagram/`.

Открытые вопросы: в новом пакете **нет нового снимка «Моя библиотека» или меню настроек**. Библиотеку следует оформить в общем визуальном стиле приложения с указанными состояниями; точную копию неизвестной вкладки без референса не обещать.
