# Проверка готовности — сценарии для ручного тестирования

- [ ] **Старт:** открыть Expo Web, главная отображается, доступно боковое меню с пунктами «Моя библиотека» и «Настройки».
- [ ] **Статус:** открыть книгу и «В библиотеку», выбрать «Читаю», закрыть/открыть карточку — статус остался.
- [ ] **Перезагрузка:** обновить страницу F5 — выбранный статус «Читаю» сохранился.
- [ ] **Прогресс:** открыть главу, пролистать, вернуться на главную, открыть снова — книга открывается примерно с сохранённого места.
- [ ] **Перезапуск:** F5 — позиция чтения осталась, блок «Вы читали» показывает последнюю книгу и адекватный процент.
- [ ] **Библиотека:** книга отображается в полке «Читаю»; перевод в «Прочту позже» меняет полку и сохраняется после F5.
- [ ] **Скрытие:** выбрать «Не интересно» — книга отсутствует в обычной выдаче; в библиотеке её можно найти и вернуть.
- [ ] **Поиск:** ввод названия книги, Enter на клавиатуре и кнопка поиска выполняют одно и то же; поиск по автору выводит автора.
- [ ] **Фильтр AND:** выбрать два жанра — в выдаче только книги, у которых есть оба; добавить статус/доступ — результаты удовлетворяют всем условиям.
- [ ] **Исключение:** исключить один жанр — нет книг с этим жанром, даже если другие параметры подходят.
- [ ] **Пустые фильтры:** сбросить всё → «Подобрать» — отображаются доступные книги, если они есть.
- [ ] **Пустой результат:** заведомо невозможное сочетание → иллюстрация/сообщение из эталонного состояния, а не белый экран.
- [ ] **Offline:** настройки → включить «Имитация отсутствия интернета» → поиск/обновление показывает offline с «ОБНОВИТЬ».
- [ ] **Retry offline:** нажать «ОБНОВИТЬ» при включённом offline → остаётся offline, без ложного успеха.
- [ ] **Retry online:** выключить offline → «ОБНОВИТЬ» → loading → реальные мок-результаты.
- [ ] **Чтение offline:** при выключенной сети можно зайти в «Моя библиотека» и открыть ранее доступную главу.
- [ ] **Нажатия:** все кнопки в основных сценариях кликабельны, модалки закрываются по кнопке и/или Back, незаметные прозрачные слои не перекрывают интерфейс.
- [ ] **Web:** `npx.cmd expo start --web` открывается без красных ошибок; нет критических ошибок в консоли браузера.
- [ ] **Android-ready:** компоненты React Native, нет обязательных web-only APIs в основном коде, сборка Expo не повреждена.
- [ ] **Git:** существующие файлы не потеряны, нет коммита/пуша без явного разрешения пользователя.
