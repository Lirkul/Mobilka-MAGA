# Иллюстрации

В папках `assets/mock-covers` и `assets/mock-avatars` лежат оригинальные учебные изображения, не копирующие обложки коммерческих произведений и не изображающие реальных авторов.

Если понадобится улучшить художественное качество, можно позже заменить одноимённые файлы по следующей творческой формуле:

- Вертикальный постер 2:3, жанровое атмосферное изображение, без логотипов и чужих названий.
- Отдельная палитра для каждого жанра: тёмное фэнтези — холодный индиго и пепел, постапокалипсис — тёплая ржавчина, киберпанк — неон, космос — глубокий синий, мистика — зелёные и чёрные оттенки.
- Основной объект крупно: башня, лунный диск, станция, ворота, лес, механический город. Не перегружать мелкими деталями.
- Сохранять файлы `book_001.png` ... `book_020.png` в размерах 520×780 пикселей и `author_01.png` ... `author_08.png` в 320×320.

Текущие обложки созданы для красивого наполнения учебной базы и воспроизведения типовых карточек книг в интерфейсе.
