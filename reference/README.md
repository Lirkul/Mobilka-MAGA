# Author.Today — MOCK KIT для учебного React Native приложения

Версия референса оригинала: **1.9.005-GMS (Android)**. Этот пакет — **НЕ исходники Author.Today**, а выдуманные данные и иллюстративные обложки для лабораторной по точному воспроизведению интерфейса.

## Состав

- `src/data/` — 8 выдуманных авторов, 20 книг, 120 глав (по 6 на книгу), 60 комментариев, 4 поста, 3 серии, статусы и настройки фильтров.
- `src/services/mockApi.js` — асинхронный локальный API, загрузка/ошибка/повтор, поиск по книгам/авторам/постам, библиотека и прогресс чтения.
- `src/utils/filterBooks.js` — фильтрация: **AND между критериями**, **ALL выбранных жанров и тегов**, исключаемые жанры и сортировка.
- `assets/mock-covers/` — 20 **выдуманных** тематических обложек в PNG, 520×780.
- `assets/mock-avatars/` — 8 стилизованных, не являющихся фотографиями реальных людей аватаров.
- `src/data/imageSources.js` — таблицы **статических `require()`** для React Native/Expo.
- `tests/filterBooks.test.mjs` — тесты фильтрации и mock API.
- `docs/CODEX_PROMPT.md` — **готовый промпт для Codex**.
- `docs/INTEGRATION.md` — шаги подключения, правила и пример использования.
- `docs/ОБЛОЖКИ_ПРЕВЬЮ.jpg` — все обложки в одном изображении.

## Как использовать с Codex (рекомендовано)

1. **Сделай коммит** текущего работающего интерфейса в `develop`.
2. Распакуй ZIP в `reference/AuthorToday_mock_kit/` — пусть Codex сначала изучит и адаптирует файлы.
3. Открой `reference/AuthorToday_mock_kit/docs/CODEX_PROMPT.md`, скопируй промпт в Codex.
4. Codex должен копировать/адаптировать данные в реальные `src/` и `assets/` проекта. **Не надо запускать приложение прямо из `reference/`**.
5. Проверь поэтапно совпадение главной с оригиналом, выдачу, фильтрацию, смену статуса и чтение.

## Быстрая проверка тестов

В корне Expo-проекта после распаковки:

```powershell
node --test reference/AuthorToday_mock_kit/tests/filterBooks.test.mjs
```

Если Codex скопировал тесты вместе с кодом в `src/`, поправь относительные импорты или оставь исходные тесты для контрольного прогона.

## Ключевой пример AND-фильтра

Выбрать *оба* жанра `Темное фэнтези` и `Боевая фантастика`, книги в процессе и бесплатные:

```js
const filters = {
  genres: ['Темное фэнтези', 'Боевая фантастика'],
  status: 'ongoing',
  access: 'free',
};
// Результат среди фикстур: book_001 и book_019.
```

Ожидаемый результат: **только `book_001` и `book_019`**. Книга, совпавшая лишь по одному жанру, не должна попасть в выдачу.

*Важно:* внутри массивов `genres` и `tags` — `every()`, между любыми заполненными критериями — AND. Исходный интерфейс имеет **радио-поля** `format`, `status` и т. п. Их значения взаимоисключающие, поэтому они не должны быть массивами с `every()`.

## Замечания

- Тексты книг, персонажи, отзывы, названия и изображения **вымышлены**. В реальном проекте желательно оставить скриншоты из `reference/screenshots/` для контроля точности интерфейса, а новые обложки использовать для наполнения списка.
- Даты мок-данных — сентябрь/октябрь 2026. Фильтры типа «не позже 7 дней» сравнивают с текущими часами; спустя время «новых книг» станет меньше. Для воспроизводимых тестов передавай `options.now`.
- Состояния библиотеки и прогресс хранятся **в памяти JS-процесса**. После перезагрузки они сбросятся. Для сохранения между запусками Codex позже может подключить `AsyncStorage`.
- `priceRub` — цена одной книги, `series.subscriptionPrice` — цена подписки на цикл. Для платной книги первые `freeChapters` глав доступны бесплатно. Настоящих платежей в задании нет.
- Сгенерированные иллюстрации — условные учебные обложки. Для художественного качества позже можно заменить PNG на отдельные изображения, сохранив имена файлов.
