# Учебный клон Author.Today

React Native + Expo SDK 58 + JavaScript. Главный экран и панель поиска повторяют
`reference/screenshots/1000017162.jpg` и `1000017163.jpg`. Структура переходов
находится в `reference/diagram`. Подключён учебный mock kit: 20 книг, 8 авторов,
120 глав, 60 комментариев, 4 поста и 3 книжных цикла.

## Запуск

```sh
npm install
npx expo start --web
```

Откройте адрес, указанный Expo (обычно `http://localhost:8081`). В инструментах
разработчика браузера включите мобильный размер, например **393 × 852**.
На широком экране интерфейс центрируется и ограничивается шириной 480.
В PowerShell с запретом запуска `.ps1` используйте `npm.cmd` и `npx.cmd`.

### Android-эмулятор в Windows

После `npm.cmd ci` запустите `Start-Android.cmd` двойным щелчком или из терминала:

```powershell
.\Start-Android.cmd
```

Нужны Android SDK с `platform-tools` и `emulator` и созданное виртуальное устройство.
Скрипт использует `ANDROID_HOME` или стандартную папку `%LOCALAPPDATA%\Android\Sdk`,
открывает `AuthorToday_API_36` (либо первое доступное устройство), ждёт загрузки Android
и запускает приложение через Expo Go. При первом запуске Expo CLI скачает и установит
совместимую версию Expo Go. Оставьте окно терминала открытым, пока работаете с приложением;
`Ctrl+C` останавливает сервер. Для выбора устройства или порта:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-android.ps1 -Avd AuthorToday_API_36 -Port 8081
```

## Что проверить

1. На главном экране видны верхняя панель, переключатель, блок «Вы читали»,
   «Популярное» и «Горячие новинки». Прокрутите экран вниз.
2. Нажмите лупу: откроется нижняя панель с затемнённым главным экраном.
3. Введите `Арсений` и нажмите синюю лупу или Enter: откроется выдача
   с отдельными разделами книг, авторов и постов. Название `Город под чёрным
   солнцем` находит книгу; `ноябрь` — пост. Пустой запрос просит ввести текст.
4. Для контрольного подбора выберите **оба** жанра «Темное фэнтези» и
   «Боевая фантастика», а в «Дополнительно» — статус «В процессе» и доступ
   «Свободный». «ПОДОБРАТЬ» должен вернуть только `book_001` и `book_019`:
   «Город под чёрным солнцем» и «Тени кристального перевала».
5. Жанры и теги работают через **AND**: каждый выбранный должен быть у книги.
   Ни одного исключённого жанра у книги быть не должно. Остальные ограничения
   тоже объединяются через AND. «СБРОСИТЬ ВСЁ» очищает ограничения. Начальная
   выдача содержит 19 из 20 книг: `book_012` уже помечена «Не интересно» в фикстурах.
6. Закройте панель нажатием на затемнение, Escape в Web или кнопкой «Назад»
   на Android. Выбранные настройки сохраняются до сброса, положение главного
   экрана сохраняется. Повторите проверку на ширине 320.

7. Откройте книгу из главного экрана или выдачи. В «В библиотеку» выберите
   «Читаю», «Прочту позже», «Прочитано» либо «Не интересно». Вернитесь в выдачу:
   неинтересная книга исчезнет. На самой карточке статус можно изменить снова.
8. Нажмите «ЧИТАТЬ». Проверьте текст, следующую/предыдущую главу и оглавление,
   возврат к книге и продолжение чтения. Прогресс сохраняется в mock API.
   У платных книг бесплатны только первые `freeChapters` глав. Платная часть
   отображает заглушку; платежей нет.
9. Проверьте ссылки на автора и цикл в книге, профиль из поиска, пост и его автора.
   В «Отзывы» карточки отображаются комментарии из набора данных.

«ВСЕ» открывает каталог с соответствующей сортировкой; «Предпочтения» — отдельную
вкладку с любимыми жанрами и рекомендациями. Меню ведёт к библиотеке и настройкам. Иконки будущих сообщений,
уведомлений и обсуждений пока декоративные. Компоновка главной сохранена.
Системные часы, индикаторы и жестовая полоса из скриншота не имитируются.
На устройстве их рисует Android; отступы учитывают safe area.

## Структура

- `src/app/` — главная, результаты, книга, автор, цикл, пост и читалка; Expo Router.
- `src/components/` — существующие карточки и секции, поля/диалоги фильтров,
  библиотечный статус, оглавление и общие состояния загрузки/ошибки.
- `src/data/` — данные mock kit, справочники и статические карты изображений.
- `src/utils/filterBooks.js` — общая AND-фильтрация.
- `src/services/mockApi.js` — асинхронные запросы и состояние библиотеки/чтения.
- `src/services/catalog.js` — адаптер API к существующим карточкам главной.
- `src/hooks/useAsyncResource.js` — загрузка при открытии/возврате, повтор запроса
  и защита от устаревшего ответа.
- `src/theme.js` — общие цвета и размеры.
- `assets/mock-covers/`, `assets/mock-avatars/` — 28 локальных PNG из mock kit.
- `assets/covers/` — сохранённые обложки предыдущего этапа; больше не используются.

Все экраны и элементы интерфейса написаны на React Native, стили —
`StyleSheet`. Иконки используют кроссплатформенный `react-native-svg`.
Roboto трёх начертаний включён в сборку через Expo Font и загружается локально.
Проект остаётся на JavaScript; `tsc` проверяет `.js` через `checkJs`.
Данные — учебные фикстуры. Реальных запросов к Author.Today нет.
Библиотека, прогресс, время последнего чтения и настройки сохраняются через
AsyncStorage (Web и Android). Дефолты создаются только при первом запуске;
сохранённые полки не перезаписываются при F5. Посты показывают имеющийся в наборе `excerpt`.

## Проверки

```sh
npx expo lint
npx tsc --noEmit
node --test reference/tests/filterBooks.test.mjs
npm test
```

В этом рабочем каталоге пакет распакован прямо в `reference/`, поэтому исходный
тест находится в `reference/tests/`, а не в `reference/AuthorToday_mock_kit/tests/`.
Тесты в `tests/` проверяют интегрированный код, контрольную пару книг,
исключения/теги, библиотеку, поиск, чтение и ошибку с повтором запроса.

При запущенном Expo Web можно выполнить проверку браузером (нужен Chrome):

```sh
node scripts/check-web.cjs
node scripts/check-reader.cjs
node scripts/check-v2.cjs
node scripts/check-preferences.cjs
node scripts/check-menus.cjs
node scripts/check-library.cjs
node scripts/check-reader-books.cjs
node scripts/check-reader-focus.cjs
node scripts/check-dz2-ui.cjs
node scripts/check-video-scenario.cjs
node scripts/check-book-progress.cjs
node scripts/check-reader-modes.cjs
node scripts/check-reader-modes.cjs --small
```

Для другого порта в PowerShell: `$env:EXPO_WEB_URL='http://localhost:8082'`.
Скрипт проверяет главную, поиск по трём типам данных, AND-подбор, статусы
библиотеки, исключение «Не интересно», чтение и ошибки браузера.
`check-reader.cjs` отдельно проверяет восстановление второй главы и фактической
прокрутки на 60%, оглавление и недоступность текста платной главы.
`check-v2.cjs` проверяет статусы/чтение после F5, четыре полки, возврат книги
из «Не интересно», сокращённый экран настроек, offline/retry/empty/loading,
независимость поиска и подбора, вкладки автора и настройки читалки.
Скриншоты проверки сохраняются в игнорируемую Git папку `.expo/verification`.

Визуальная доработка ДЗ2 описана в [списке расхождений и проверок](docs/DZ2_VISUAL_REVIEW.md).
Проверить её в текущей сессии можно на `http://localhost:8085`: главная → лупа →
«ПОДОБРАТЬ» либо поиск по названию. `check-dz2-ui.cjs` проверяет оба сценария,
окна параметров, возврат и размещение элементов на ширине 320/393/1440.

Доработка по [видео ДЗ1](reference/video/README.md) описана в
[DZ2_VIDEO_MATCH.md](docs/DZ2_VIDEO_MATCH.md). `check-video-scenario.cjs` проверяет
дерево жанров, движение панелей, нижний выбор статуса и читалку: пять фонов,
яркость и жест, шрифт, выравнивание, постраничный режим, перемещение ползунком,
скрытие панелей и восстановление после F5. Выбор родительской категории жанра
означает одно широкое условие; несколько отдельных жанров по-прежнему требуют
наличия всех выбранных одновременно. Исключённая категория блокирует её поджанры.

## Тексты книг

Для каждой из 20 книг предусмотрены шесть собственных учебных глав с разными
названиями и событиями. Тексты написаны для демонстрационного каталога по его
аннотациям; это не оригинальные произведения с Author.Today. Общие шаблонные
абзацы, одинаковые вступления и повторение текста для длины не используются.

Метаданные глав находятся в `src/data/chapterMetadata.js`, тексты — в
`src/data/reading/`, сборка данных — в `src/data/chapters.js`. Идентификаторы,
принадлежность книгам, даты и бесплатность глав сохраняют прежние значения,
поэтому сохранённые статусы и ссылки на место чтения продолжают работать.
Читалка получает конкретную главу через `getChapter(bookId, chapterId)`.

`tests/chapterContent.test.mjs` проверяет все 120 глав: связь с книгами,
неизменность метаданных, уникальность текста, абзацев и названий и отсутствие
глав, отличающихся лишь заменой нескольких слов. `scripts/check-reader-books.cjs`
открывает первые две главы всех книг через интерфейс и проверяет переход
между разными книгами без перезагрузки, отдельный прогресс и платные ограничения.
`scripts/check-reader-focus.cjs` проверяет выбор через оглавление, смену главы,
возврат из настроек и F5: адрес, текст и фактическая прокрутка должны оставаться
на текущей главе. При смене главы её ID обновляется в URL без добавления
лишнего шага в историю переходов.

## Асинхронность и ДЗ3

Все запросы возвращают Promise; UI показывает загрузку, ошибку и «Повторить».
Демонстрационные сбои включаются из кода через `mockApiControl`:

```js
import { mockApiControl } from './src/services/mockApi';

mockApiControl.setLatency(850);
mockApiControl.failNextRequest(); // один следующий запрос завершится ошибкой 503
```

`await mockApiControl.reset()` восстанавливает фикстуры, прогресс, библиотеку и
настройки; это средство для тестов, приложение не вызывает его при старте.
Общие компоненты не используют браузерные API. Добавлена совместимая с SDK
зависимость `@react-native-async-storage/async-storage` через Expo install.
Android APK на этом этапе не собирался; `ios/` и `android/` вручную не создаются.
Android bundle и все локальные ресурсы проверяются без создания нативных папок:

```sh
npx expo export --platform android --output-dir .expo/verification/android-export
```

## Предпочтения на главной

Переключитесь с «Все книги» на «Предпочтения». Карточка «Любимые жанры» повторяет
новый референс: 20 кнопок с контурными иконками, шестерёнка, сворачивание блока,
«Меньше/Больше жанров» и «Сбросить». Исключённая пользователем категория в
справочник не добавлена. Шестерёнка открывает окно группового выбора;
«ОТМЕНА» не сохраняет черновик, «ВЫБРАТЬ» применяет его.

Выбор и сброс сохраняются через AsyncStorage. После F5 откройте вкладку снова:
выбранные жанры останутся отмеченными. Старые сохранения получают пустой список
предпочтений, сохраняя библиотеку и прогресс. Локальная запись доступна и при
имитации отключения сети; ошибка сохранения показывает «Повторить».

Предпочтения определяют порядок блока «Рекомендуемое»: сначала идут книги с
большим числом совпавших интересов, затем учитывается популярность. Это отдельная
сортировка рекомендаций. Вкладка «Все книги», текстовый поиск и строгий AND-подбор
сохраняют прежнее поведение. Скрытые книги не попадают в рекомендации. Учебный
каталог не содержит произведений для каждого из 20 жанров; выбор такого жанра
сохраняется. Если совпадений нет, сохраняется порядок по популярности.

Проверка: выберите «Детектив» — в начале рекомендаций появятся «Двор теней» и
«Цвет стеклянных улиц». Обновите страницу, проверьте выбор, сбросьте его и
повторите обновление. `node scripts/check-preferences.cjs` проверяет этот сценарий,
модальное окно, независимость поиска и размещение кнопок на ширине 320/393/1440.

## Меню и карточки библиотеки по новым референсам

Гамбургер открывает левую панель шириной около 71% экрана. «Книги» и «Сообщество»
раскрываются внутри прокручиваемого меню. Логотип возвращает на главную,
«Популярные» и «Новинки» открывают каталог с нужной сортировкой, «Аудиокниги»
применяют формат audio. «Рекомендуемые» ведут во вкладку «Предпочтения»,
«Полный список жанров» открывает выбор жанров, «Расширенный поиск» — панель
поиска и подбора. «Общие настройки» открывают существующий экран настроек.
Панель поиска внутри меню использует тот же native Modal, чтобы окна не
накладывались друг на друга на Android.

Аватар открывает правую панель с синим геометрическим фоном и именем
**Bespalko Egor**. Отсюда открывается «Моя библиотека». «Добавить» и «Учетная
запись» раскрываются. Выход из демонстрационного профиля требует подтверждения,
сохраняется после F5 и оставляет библиотеку/прогресс на устройстве. Для возврата
откройте аватар и нажмите «Войти как Bespalko Egor». Это локальная имитация
сессии, без настоящей авторизации.

Остальные пункты меню отображаются по референсам, но их полноценные разделы
ещё не реализованы: они показывают явное пояснение или пустое состояние внутри
панели. Кошелёк показывает демонстрационный нулевой баланс, без платежей.
Счётчики конкурсов и литмобов «4»/«9» повторяют снимок и не являются живыми данными.

Библиотека использует отдельный `LibraryBookCard`: обложку, название, автора,
цикл, процент/полосу прогресса, объём, доступ и «Читать». Объём посчитан по
текстам глав mock kit; процент и полоса показывают прочитанную часть всей книги.
Нажатие на карточку/значок книги открывает описание. Звёздочки открывают
существующий выбор статуса прямо в библиотеке; книга перемещается на нужную
полку. «Читать» продолжает сохранённую главу. Облако объясняет доступ без сети:
главы уже включены в приложение, отдельного скачивания нет, платные ограничения
сохраняются. Изображения из референсов не используются вместо интерфейса.

Проверка: `node scripts/check-menus.cjs`. Скрипт проверяет обе панели,
раскрывающиеся пункты и переходы, карточку библиотеки, прямое чтение,
перемещение между полками, сохранение данных после выхода и размеры 320/393/1440.

## Полки и инструменты библиотеки

Библиотека использует новый референс с выпадающим списком вместо горизонтальных
вкладок. В шапке — «Назад», поиск, фильтры и сортировка; для открытия общих меню
вернитесь назад. Список содержит «Все», «Читаю / слушаю», «Отложено»,
«Прочитано», «Оплачено», «Понравилось», «Реакции» и «Не интересно».
Выбранная полка выделяется синим, счётчики рассчитаны по состоянию библиотеки.
«Все» исключает неинтересные книги; увидеть и вернуть их можно на отдельной полке.
Выбранная полка и сортировка записываются в URL через Expo Router и сохраняются
при обновлении Web-страницы.

Поиск проверяет названия и имена авторов без учёта регистра и е/ё. Фильтры
библиотеки задают включённые/исключённые жанры, формат, статус и доступ;
каждое условие и все включённые жанры должны выполняться одновременно.
Счётчики в выпадающем списке показывают всю библиотеку, а поиск и фильтры
сужают выбранную полку. Доступны сортировки по последнему чтению, названию,
автору, обновлению и прогрессу. Сброс поиска/фильтров не меняет статусы книг.
Общий поиск и подбор каталога сохраняют собственные условия.

Оплата и личные отметки отделены от цены и общей статистики книги:
`purchasedBookIds` содержит записи об оплате, `bookFeedback` — личные лайки и
реакции. В исходном наборе эти данные пусты, поэтому соответствующие полки
показывают 0. Цена книги не считается покупкой, а общие лайки — личными.
Платежи, постановка лайков и реакций книгам на этом этапе не добавлены.
Старые сохранения получают пустые поля, сохраняя прежнюю библиотеку и прогресс.

Проверка: `node scripts/check-library.cjs`. Скрипт проверяет восемь полок,
счётчики, выбор после F5, поиск, сортировку, AND-фильтры, сброс/отмену,
пустые состояния, offline и размещение списка на ширине 320/393/1440.

## Итерация 2: библиотека, offline и автор

Левое меню (гамбургер в шапке) содержит «Книги», «Сообщество» и общие настройки.
«Моя библиотека» открывается из правого меню по аватару. В библиотеке восемь полок, в том числе «Не интересно»: оттуда
можно открыть карточку и вернуть книгу в другую полку. Прогресс виден и в
библиотеке, и на главной. «Вы читали» выбирает книгу по `lastReadAt`, а не
первый элемент полки. Начало чтения добавляет книгу в «Читаю», если статуса
ещё нет или он был «Прочту позже».

На экране «Настройки» доступны переключатель «Имитация отсутствия интернета» и
«Задержка ответа» (240/1500 мс). Их значения сохраняются после F5. Переключатель
имитирует offline только внутри mock API, физическая сеть устройства не меняется.
Поиск, каталог и профиль автора требуют имитируемой сети;
библиотека, метаданные книг и главы доступны локально. Все учебные главы
входят в сборку; ограничения платных глав продолжают действовать. На offline
экране доступны последние книги, «ОБНОВИТЬ» и «В БИБЛИОТЕКУ».

На экране нет учебного заголовка, пояснений о mock API и локальном хранении,
переключателя пустой выдачи и кнопки ошибки следующего запроса. Программные
средства `mockApiControl.failNextRequest()` и `updateSettings({ emptyResults: true })`
сохранены для тестов. Пустые результаты в интерфейсе можно проверить запросом,
которому не соответствует ни одна книга, автор или пост: появится сова — отдельная
векторная иллюстрация React Native SVG. Повтор запроса и загрузка проверяются
через offline и задержку ответа.

В профиле автора работают подписка и личная заметка с сохранением, вкладки
«Произведения» (три колонки), «Блог» (посты и реакции), «Иллюстрации» (две
колонки, просмотр и переход к книге). Самостоятельных оригинальных иллюстраций
в пакете нет, поэтому галерея использует учебное оформление книг, без вырезок
из скриншотов. Сообщения, гостевая и награды автора в эту итерацию не входят.

В читалке шестерёнка открывает пять фонов, шрифт и размер, выравнивание,
режим чтения, яркость страницы, жест и дополнительные параметры. Эти
настройки сохраняются. Нижний ползунок перемещает текст, нажатие на текст
скрывает/возвращает панели. Прогресс записывается после прокрутки с небольшой
задержкой и при уходе с экрана; индикатор показывает процент всей книги.
Очередь записи принадлежит API и сохраняется при закрытии читалки. Восстановление
чтения ждёт незавершённые записи этой книги, чтобы медленное хранилище не вернуло
предыдущую главу. Этот сценарий проверяется с задержкой записи в Node-тестах.

Общий процент рассчитывает `src/utils/bookProgress.js`: объём предыдущих глав
плюс прочитанная доля текущей главы, делённые на объём всех глав. Главы учитываются
по длине текста, включая платное продолжение. 100% появляется в конце последней
главы. Читалка, библиотека, главная, результаты поиска и сортировка по прогрессу
используют этот общий показатель.

Для продолжения чтения сохранён прежний формат `chapterId` + `percent`
(локальная позиция в главе). Ползунок «Позиция в главе» управляет этой позицией.
Общий `bookPercent` вычисляется при получении данных и для отображения в читалке;
старые сохранения не перезаписываются и не требуют сброса. Метаданные оглавления
содержат `textLength`, текст главы по-прежнему запрашивается отдельно.
`tests/bookProgress.test.mjs` проверяет длины, границы, совместимость сохранений
и сортировку; `check-book-progress.cjs` — одинаковый процент во всех экранах,
переход в следующую главу и восстановление места после F5.

Читалка использует единый режим: вертикальная прокрутка останавливается в любом
месте, а горизонтальный свайп двигает страницу вслед за пальцем влево или вправо.
Соседние экраны текста появляются сбоку, с перекрытием в одну строку.
Свайп вперёд на последнем экране открывает следующую главу; обратный свайп в начале
главы возвращает на последний экран предыдущей. Платные главы сохраняют ограничения.
Переключать режим в настройках больше не нужно;
старые сохранения с `scroll` и `paged` открываются в том же едином представлении.

Короткое нажатие в центре показывает или скрывает панели. Панели расположены
поверх текста и не меняют его положение. При начале листания и вертикальной
прокрутки панели скрываются. Длительное нажатие для выделения и остановка
инерционной прокрутки не открывают панели. Подробные настройки
открываются шестерёнкой; оглавление, переходы между главами и сохранение позиции
остаются доступны.

`check-reader-gestures.cjs` проверяет касания, оба направления свайпов,
свободную прокрутку, сохранность текста и восстановление после F5 на 393 × 852;
`--small` повторяет сценарий на 320 × 568. Прежняя команда
`check-reader-modes.cjs` запускает эту же проверку.
`check-reader-flow.cjs` отдельно проверяет движение текста по горизонтали во время
жеста, автоматические переходы между главами, восстановление позиции и платный доступ.

Основные новые файлы: `src/services/appState.js`, маршруты `library.js` и
`settings.js`, компоненты `NavigationMenu`, `RecentBooks`, `EmptyState`,
`AuthorResultItem`, `PostCard`, `ReaderSettingsModal`. Слой состояния принимает
адаптер хранения, поэтому Node-тесты проверяют те же операции на независимом
хранилище без импорта нативного модуля. Приложение подключает AsyncStorage
в корневом `_layout.js`. Новые референсы в `reference/AuthorToday_refs_v2/`
не изменены.
