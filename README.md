# Учебный клон Author.Today

React Native + Expo SDK 58 + JavaScript. Первый этап — главный экран по
`reference/screenshots/1000017162.jpg` и нижняя панель поиска по
`1000017163.jpg`. Структура переходов находится в `reference/diagram`.

## Запуск

```sh
npm install
npx expo start --web
```

Откройте адрес, указанный Expo (обычно `http://localhost:8081`). В инструментах
разработчика браузера включите мобильный размер, например **393 × 852**.
На широком экране интерфейс центрируется и ограничивается шириной 480.
В PowerShell с запретом запуска `.ps1` используйте `npm.cmd` и `npx.cmd`.

## Что проверить

1. На главном экране видны верхняя панель, переключатель, блок «Вы читали»,
   «Популярное» и «Горячие новинки». Прокрутите экран вниз.
2. Нажмите лупу: откроется нижняя панель с затемнённым главным экраном.
3. Введите `таксист` и нажмите синюю лупу или Enter: появится одно совпадение
   из локального каталога. Для неизвестного названия будет показано 0.
4. По исходному фильтру «Темное фэнтези» кнопка «ПОДОБРАТЬ» найдёт
   «Дворник 32-го уровня. Том 12». «СБРОСИТЬ ВСЁ» очищает строку и все
   ограничения: после сброса подбор возвращает все шесть книг.
5. Измените жанры, исключения, формат или сортировку. В «Дополнительно»
   доступны статус, форма и доступ. Подбор использует эти значения отдельно
   от строки поиска. Для аудио в локальном каталоге совпадений нет.
6. Закройте панель нажатием на затемнение, Escape в Web или кнопкой «Назад»
   на Android. Выбранные настройки сохраняются до сброса, положение главного
   экрана сохраняется. Повторите проверку на ширине 320.

На этом этапе действия поиска показывают совпадения внутри панели; переходы
к результатам, книге, чтению, профилю и прочим экранам ещё не добавлены.
Надпись «ВСЕ» и иконки будущих разделов пока декоративные. «Предпочтения»
открывает ту же панель подбора без создания отдельного экрана.
Системные часы, индикаторы и жестовая полоса из скриншота не имитируются.
На устройстве их рисует Android; отступы учитывают safe area.

## Структура

- `src/app/` — единственный экран и корневой layout Expo Router.
- `src/components/` — шапка, карточка, секция книг, история чтения, панель
  поиска и переиспользуемые строки/диалоги фильтров.
- `src/data/` — шесть книг и описание доступных фильтров.
- `src/services/catalog.js` — независимые `searchBooksByTitle` и `discoverBooks`;
  точки подключения будущих сценариев и API.
- `src/theme.js` — общие цвета и размеры.
- `assets/covers/` — локальные обложки, извлечённые из исходного скриншота.

Все экраны и элементы интерфейса написаны на React Native, стили —
`StyleSheet`. Иконки используют кроссплатформенный `react-native-svg`.
Roboto трёх начертаний включён в сборку через Expo Font и загружается локально.
Проект остаётся на JavaScript; `tsc` проверяет `.js` через `checkJs`.
Данные фильтров — учебные фикстуры, не реальные метаданные Author.Today.

## Проверки

```sh
npx expo lint
npx tsc --noEmit
```

При запущенном Expo Web можно выполнить проверку браузером (нужен Chrome):

```sh
node scripts/check-web.cjs
```

Скрипт проверяет локальные обложки, оба сценария поиска, изменение и сброс
фильтров, закрытие панели, мобильную и настольную ширину, ошибки браузера.
Скриншоты проверки сохраняются в игнорируемую Git папку `.expo/verification`.

Android APK на этом этапе не собирался; `ios/` и `android/` вручную не создаются.
