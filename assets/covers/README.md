Обложки извлечены из предоставленного `reference/screenshots/1000017162.jpg`
для учебного воспроизведения интерфейса Author.Today 1.9.005-GMS.
Области включают оригинальную плашку «Эксклюзив» с выступом за край обложки.
Оригинальный скриншот не изменён. Изображения включены в приложение локально,
сетевые запросы для каталога не используются.

Повторное извлечение в Windows: `powershell -ExecutionPolicy Bypass -File scripts/extract-covers.ps1`.
